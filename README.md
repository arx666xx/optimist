# NetOptimizer

Настольное приложение для Windows 11, которое наглядно показывает **все сетевые соединения** и позволяет ими управлять: закрывать соединения, завершать/приостанавливать процессы, менять приоритет, блокировать программы в брандмауэре. Цель — быстро находить и убирать лишние подключения и оптимизировать сеть.

> ⚠️ Инструмент для **собственного ПК** и требует прав администратора (закрытие TCP-соединений и управление процессами без этого невозможно). При запуске появится запрос UAC.

## Возможности

- **Список всех соединений** TCP и UDP (IPv4 и IPv6): протокол, процесс, PID, локальный и удалённый адрес, состояние.
- **Автообновление** каждые 2 секунды (можно выключить).
- **Поиск и фильтры**: по процессу/адресу/порту, скрытие локальных (loopback) соединений, «только активные», «только подозрительные».
- **Подсветка подозрительных** соединений (например, процесс запущен из `Temp`/`Downloads` и куда-то стучится).
- **Действия по правой кнопке мыши**:
  - 🔌 Закрыть соединение (IPv4 TCP, через `SetTcpEntry`).
  - ✖ Завершить процесс (вместе с дочерними).
  - ⏸ / ▶ Приостановить / возобновить процесс.
  - Изменить приоритет процесса (Idle … High).
  - 🛡 Заблокировать / разблокировать программу в брандмауэре Windows.
  - 🌐 Определить хост по IP (обратный DNS).
  - 📁 Открыть расположение исполняемого файла.
  - 📋 Скопировать строку.

## Как получить готовый `.exe` (без установки Visual Studio)

Сборка происходит автоматически на GitHub через GitHub Actions — на настоящей Windows-машине.

1. Загрузите этот проект в свой репозиторий на GitHub (см. ниже).
2. Actions соберёт приложение автоматически. Готовый `NetOptimizer.exe`:
   - **Из любого коммита** — вкладка **Actions → последний запуск → Artifacts → `NetOptimizer-win-x64`**.
   - **Из релиза** — создайте тег `v1.0.0`, и `.exe` появится в разделе **Releases**:
     ```bash
     git tag v1.0.0
     git push origin v1.0.0
     ```
3. Скачайте `NetOptimizer.exe` и запустите — это самодостаточный файл, .NET устанавливать не нужно.

## Локальная сборка (если есть .NET 8 SDK)

```bash
# обычный запуск
dotnet run --project src/NetOptimizer/NetOptimizer.csproj

# собрать один self-contained .exe
dotnet publish src/NetOptimizer/NetOptimizer.csproj -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```
Готовый файл: `publish/NetOptimizer.exe`.

> Примечание: WPF собирается только на Windows. `dotnet build` на Linux/macOS для этого проекта не сработает — используйте Windows или GitHub Actions (уже настроен).

## Технические детали

- Перечисление соединений — через `netstat -ano` (надёжно, без хрупкого маршалинга структур), затем сопоставление PID → процесс через `System.Diagnostics`.
- Закрытие соединения — `iphlpapi.dll SetTcpEntry` с состоянием `DELETE_TCB` (только IPv4 TCP; для IPv6/UDP завершайте процесс).
- Приостановка/возобновление — `ntdll.dll NtSuspendProcess` / `NtResumeProcess`.
- Блокировка — правила `netsh advfirewall firewall`.

- 🚦 **Ограничение скорости** для конкретного процесса (как в NetLimiter — требует драйвера WFP).
- 📜 **История и логирование** соединений, оповещения о новых исходящих подключениях.
- 🧩 **Правила и авто-действия**: «если процесс X из Temp открыл соединение — блокировать».
- 🗂 **Группировка по процессу**, дерево процессов.
- 💾 **Экспорт в CSV/JSON**.
- 🔔 **Значок в трее** + фоновый мониторинг.
- 🔐 **Проверка цифровой подписи** exe (подозрительно, если не подписан).
- 🌗 Светлая/тёмная тема, настройки интервала обновления.
